# Электронный журнал студентов

Учебное приложение на Flask, JavaScript и SQLite.

## Функционал

- Добавление, переименование и удаление пустых групп.
- Управление предметами.
- Поиск, добавление, редактирование и перевод студентов.
- Выставление, изменение и удаление оценок.
- Отчёты по группам, студентам без оценок и студентам с двойками.

## Запуск

После установки зависимостей и подготовки базы запустите приложение из папки проекта:

`.\.venv\Scripts\python.exe app.py`

Затем откройте в браузере:

http://127.0.0.1:5000/

Приложение работает локально, пока запущен сервер.
